## 8. Header Analysis (3 Packets)

Packets analyzed: Frame 1, Frame 4, Frame 6.

1. Why is TTL not zero?
   - TTL is initialized by sender (64 here) and decremented per router hop. On
     loopback (`127.0.0.1`), packets do not traverse routers, so TTL remains 64
     and never reaches zero.

2. Why do packet sizes differ?
   - Different TCP segments carry different payload/control content. For example,
     SYN packets are 60 bytes, pure ACK packets are 52 bytes, and packets with
     payload (`PSH,ACK`) can be 54 or 60 bytes.

3. What information does protocol field provide?
   - It identifies the transport protocol carried by IP. Here `PROTOCOL_NO=6`
     means TCP.

4. What could happen if protocol field is modified?
   - The receiver/network stack may pass the packet to the wrong protocol
     handler, causing parsing failure or packet drop.

5. What do protocol-specific fields reveal?
   - TCP source/destination ports identify flow endpoints, and TCP flags reveal
     connection phase (SYN handshake, ACK confirmation, PSH data, FIN close).

## 10. Reflection Answers (<= 300 words)

Raw sockets require root privileges because they allow direct access to packet
headers and low-level traffic that can bypass normal transport-layer safety
controls. This access can be abused for spoofing, scanning, or packet
manipulation, so the OS restricts it.

Raw sockets differ from normal TCP/UDP sockets because applications receive and
interpret headers directly. In TCP/UDP sockets, the kernel handles most
protocol logic (connection state, reliability, segmentation/reassembly,
checksums) and applications read only payload-oriented streams/datagrams.

One advantage of raw sockets is full visibility/control of packet-level
behavior, useful for protocol debugging and security tooling. One limitation is
higher complexity and privilege requirements; implementation mistakes can easily
cause incorrect parsing or unstable behavior.

One cybersecurity application is intrusion detection or custom packet inspection
where tools analyze live header/flag patterns (for example, SYN flood patterns
or anomalous protocol usage).
